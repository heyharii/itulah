Yang perlu ada supaya flow ini jalan

Sekarang toko, pool, dan bagan akun hanya ada karena migrasi Postgres mengisinya. Belum ada API untuk membuatnya dari hub.

Endpoint yang dipanggil wizard

  1. POST /setup/company — nama, bentuk usaha; membuat unit HO + site kantor (+ gudang bila dicentang) dan pool gudang.
  2. POST /units/stores (terima array) — per toko, dalam satu transaksi: unit, site toko, pool lantai/gudang toko/reject, pool retur di gudang, origin sync + kode pasang. Menggantikan generate_series(1,13) di 0002.
  3. POST /setup/books — pasang template 40 akun (outputs/coa_thirty/chart40.json) + tautan default scope ALL / SITE_KIND, buka periode pertama, aktifkan metode bayar. Mode impor menyimpan file dan hasil pencocokan untuk diperiksa Finance.
  4. GET /setup/tasks — daftar tugas beranda dihitung dari data (bukan flag): ada user lain? rekening bank? node per toko? NPWP?

Harus beres dulu

  1. Tabel unit, site kind OFFICE/WAREHOUSE/SHOP dengan timezone; site.edge_node_id boleh kosong sampai node dipasang.
  2. Hapus hard-code "dc" (store_money.rs, claims.rs, sync.rs, allotments.rs) dan UTC+7 (acquirer.rs, finance_control.rs).
  3. Bagan akun klien keluar dari migrasi 0348/0122/0381 → jadi data import.
  4. Admin pertama dari env INVENTORY_BOOTSTRAP_ADMIN_PASSWORD → layar daftar saat DB kosong, lalu langsung masuk wizard ini.
